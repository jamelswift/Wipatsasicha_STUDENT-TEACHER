# Student Teacher Card - HTML/CSS/JS

แปลงมาจาก Next.js เป็น HTML/CSS/JavaScript บริสุทธิ์

## ไฟล์ที่ใช้

- **index.html** - โครงสร้าง HTML หลัก
- **styles.css** - สไตล์ทั้งหมด
- **script.js** - JavaScript สำหรับสร้างบาร์โค้ด
- **public/** - โฟลเดอร์เก็บไฟล์ static (รูปภาพ, icon, ฯลฯ)

## วิธีใช้

1. เปิดไฟล์ index.html ในเบราว์เซอร์
2. หรือใช้ Local Server:
   - Python: python -m http.server 8000
   - Node.js: 
px http-server
